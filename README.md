# AI Practitioner course materials

Slides, labs and lab files for the AI Practitioner course by Redstone Logic.

## Get the files

Clone into `~/course-materials`:

```bash
git clone https://github.com/Redstone-Logic/ai-practitioner-course.git ~/course-materials
```

No git? Use **Code > Download ZIP** on GitHub and unzip it to the same folder.

## Open the slides

Open `index.html` in a browser for the course map, or open any deck directly.
Arrow keys move between slides.

| Files | What they are |
|-------|---------------|
| `1-module-*.html` to `15-module-*.html` | The core modules |
| `1-lab-*.html` to `15-lab-*.html` | The lab for each module |
| `P*.html` | Put it to work: practical labs, plus modules and labs for the later topics |
| `course-sample/`, `course-sample-april/` | Brightside Landscaping office files the labs use |
| `crew-log/`, `contracts/`, `wiki-may/`, `scheduled/`, `week-october/` | More Brightside files for the later labs and the capstone |
| `hooks/`, `skills/` | Example hooks and skills for modules 7 and 11 |
| `AGENTS-template.md`, `commands-card.md` | Templates you copy into your own work |
| `tramp-one-pager.pdf` | The T.R.A.M.P. prompting framework |
| `redstone-skills/` | Where to get the Redstone skills plugin |
