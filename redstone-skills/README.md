# Redstone skills

The Redstone skills plugin lives in its own repository, so you always get the
current version:

https://github.com/Redstone-Logic/redstone-skills

Install it from GitHub instead of this folder:

```bash
claude plugin marketplace add Redstone-Logic/redstone-skills
claude plugin install redstone-skills@redstone-logic
```

Get updates later with `claude plugin update redstone-skills@redstone-logic`,
then restart Claude Code.
